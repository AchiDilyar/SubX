# SubX 功能图标集

共 64 个透明背景 PNG，均为 512 × 512 像素。浅灰线条（#E2E2E2）适配 SubX 的中性深色界面，交互强调色参考 #173E76。文件位于 `png/`，`preview-dark.png` 为深色预览，`raw/` 为生成原图，四张 `*-qa.png` 为紫红背景检查图。

图标按功能英文命名：

- 工程与文件：new-project、open-project、recent-project、save、copy、import、export、video、monitor。
- 界面与操作：settings、style、add、play、pause、undo、redo、info、chevron-right、edit、back、delete、quit、check、keyboard、external-link、close、help。
- 字幕与时间轴：add-track、remove-track、add-subtitle、split-bilingual、select、link、snap、visible、hidden、lock、unlock、fullscreen、exit-fullscreen、razor、cut、select-forward、select-backward、trim-start、trim-end、marker、wave-symmetric、wave-asymmetric、wave-off。
- 后续功能：mute、volume、zoom-in、zoom-out、clock、subtitles、blank-video、import-document、bilingual、language-link、hardware、export-video、project-settings、playhead。

新增的 remove-track 图标在生成底稿基础上重新绘制了减号，其余根据生成图切分并去除背景。已检查每张图的透明通道、画布边缘，并以对比背景和深色背景复核完整性。图标为位图设计素材；小尺寸界面若需清晰缩放和动态变色，后续应制作和验收对应矢量版本。

本交付是素材集，尚未替换应用中的现有图标。
