# SubX 0.1.0-dev.1 发布说明（候选）

> 状态：公测候选，尚未正式发布。当前版本用于内部验收和首批试用，不建议直接用于生产交付。

## 这个版本能做什么

- 在一条多轨时间轴上导入、编辑、导出 SRT / ASS / WebVTT 字幕，并兼容 SSA v4 样式。
- 拖拽、裁剪、分割、框选、吸附和链接上下轨，实时预览字幕渲染。
- 自动保存与崩溃恢复；撤销/重做有内存上限。
- QC 检查 CPS、时长、空行、行尾空格、同轨重叠和标点，并支持批量修复。
- 文本工具处理大小写、首字母、句首和多余空格；接入系统英文拼写检查。
- 时间码支持毫秒、非丢帧、丢帧显示；帧率转换功能已按用户要求移除。
- 记录已校对/待校对进度，只看待校对，并支持多选批量改时长、平移、样式和共享字号。
- 单轨导出、双语合并导出、全部可见轨道批量导出，以及 Windows 编码/换行预设。
- 检查工程字体缺失，提示预览回退；内置 FFmpeg/FFprobe 合成带字幕的视频。
- 合成面板显示源视频容器、色彩空间、HDR 类型和音轨格式；默认沿用源容器，可自定义视频码率、重编码或复制音频流；HDR 源可选择保留 HDR 或转 SDR。
- 开启 Chromium 可访问性，辅助技术可以读取字幕正文和时间字段。

- 发布文件 SHA-256 见 `out/release-manifest.json`。

## 安装与启动

- macOS：从 `out/SubX-darwin-arm64/SubX.app` 直接启动，仅用于验收，不安装到「应用程序」。
- Windows：当前只有 CI 构建产物和安装器检查，尚未完成真实桌面启动验收。
- 安装包未做 Developer ID 签名/公证，Windows 安装包也未做证书签名；系统可能提示来源不明。
