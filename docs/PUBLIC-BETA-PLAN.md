# SubX 首个可用公测版计划清单

- 版本目标：`0.9.0-beta.1`
- 文档定位：面向“能交给真实字幕制作者使用”的第一个公测版本，给出范围、顺序、验收标准与发布清单。
- 产品主文档：`PLAN.md`（本地，不随源码发布）。本文与 `PLAN.md` 冲突处见 §12。
- UI 审计：`docs/UI-UX-AUDIT.md`
- 当前基线：`0.1.0-dev.1`，SRT/ASS 多轨编辑闭环已跑通，31 个单测 + 356 条桌面 PASS 通过。
- 说明：文中行号以 2026-11-23 当前工作区为准；后续改动若行号漂移，以函数名、选择器名与验收标准为准。

## 1. 公测定义与完成标准

### 1.1 目标用户与核心承诺

目标用户：个人字幕制作者、小团队剪辑/翻译，主要在 macOS 与 Windows 桌面上处理 SRT / ASS 字幕。

公测版必须兑现的承诺：

1. 打开视频或空白视频，导入 SRT / ASS，在时间轴上完成增删改、拖动、裁剪、缩放、吸附与撤销。
2. 双语字幕可拆分到上下轨、建立/解除链接、联动拖动，并按规则合并导出。
3. 用 J/K 长按给 TXT 文稿打轴，打轴结果随工程保存并可恢复。
4. 有最基本的专业质检：CPS/阅读速度、最短/最长时长、空行、行尾空格、同轨重叠。
5. 工程不会因为崩溃或误操作丢内容：自动保存 + 崩溃恢复 + 明确撤销。
6. 能导出 SRT / ASS，并把字幕烧录进 MP4；macOS 与 Windows 安装后都能完成这条链路。

### 1.2 公测发布门槛（全部满足才发）

- [ ] P0 清单 100% 完成，P1 清单 ≥80%（剩余项有明确降级说明）。
- [ ] 单元测试、桌面 smoke、双平台安装后核心流程回归全部通过。
- [ ] 连续 3 天日常使用无数据丢失、无崩溃阻断；崩溃恢复演练通过。
- [ ] 首次启动 30 秒内能完成“打开视频 → 导入字幕 → 看到预览”的主路径。
- [ ] 已知问题清单、快速上手、快捷键、反馈入口随安装包提供。
- [ ] macOS 与 Windows 各一台干净机器完成安装/卸载/文件关联/合成视频验收。

### 1.3 明确不在公测范围

- 广播级 SCC/TTML/STL 交付、EBU 时码、HDR/SUP。
- 语音识别自动打轴、AI 翻译、云端协作。
- 音频独立导入与自动对齐（先保留视频音轨波形）。
- ASS 行内标签的可视化图形编辑（先保留文本编辑 + 实时预览）。
- 自动更新服务与账号体系。

| 专业质检 | 无 CPS/时长/空行/行尾空格 QC | 交付质量不可控，P1 |
| 格式矩阵 | 无 VTT、SSA v4、GBK、导出编码/换行选项 | 与外部工具协作受限，P1 |

| 字体 | 无字体选择器/缺失检测/合成前检查 | 预览与成片可能不一致，P1 |

## 3. 里程碑与顺序

| 里程碑 | 目标 | 主要工作 | 预计 |
| --- | --- | --- | --- |
| M0 视觉与可用性基线 | 首次使用不迷路，关键状态可见 | 本轮已做空态/待校对/焦点/状态栏/字幕信息/缺失媒体；剩余禁用原因、加载态、全屏空态、令牌收敛 | 1–2 轮 |
| M1 数据安全与核心编辑 | 不丢数据，能改时间与文本 | 自动保存/崩溃恢复；整体平移；查找替换；撤销内存上限 | 2–3 轮 |
| M2 专业字幕能力 | 达到“可交付”的字幕质量 | QC 面板；拼写/大小写/修剪；帧率转换与时码；VTT/SSA/GBK/导出编码；批量编辑；通用校对进度 | 3–4 轮 |
| M3 双语与交付闭环 | 双语可合并导出，批量导出可复用 | 合并上下轨导出；全部轨道批量导出；导出预设；字体检查；5000 块压测 | 2–3 轮 |
| M4 发布 | 双平台安装包可交付 | Windows FFmpeg/安装器/文件关联；macOS 打包与签名；安装后回归；文档与已知问题 | 2 轮 |

顺序原则：先数据安全，再专业能力，最后发布链路；UI 清单与功能里程碑并行，但每个里程碑结束都要跑一次桌面 smoke 与截图回归。

## 4. P0 公测阻断清单

### P0-1 自动保存与崩溃恢复

- 用户可见行为：编辑后 5–15 秒防抖写入 `userData/autosave/<docId>.subx`（含未应用的正文/样式草稿）；异常退出后启动时提示「恢复 / 丢弃」；正常保存或放弃后清理；恢复动作可撤销。
- 验收标准：
  - [ ] 编辑后 15 秒内生成自动保存文件，内容与当前工程一致。
  - [ ] `kill -9` 主进程或渲染进程后重启，能恢复到最后一笔编辑（含草稿），标题标记未保存。
  - [ ] 正常退出无残留 autosave；选择丢弃后不再提示。
  - [ ] 大工程（5000 条）自动保存不造成明显卡顿（<50ms 主线程占用）。
- 改动面：`src/main/main.mjs`（IPC、userData、复用 `writeAtomically`）、`preload.cjs`、`workspace.mjs`（脏状态/草稿快照、恢复 UI）、`index.html`（恢复对话框）、`test/`、桌面 smoke。
- 工作量：M；风险：中（写入频率、退出竞态）。

### P0-2 时间整体平移

- 用户可见行为：新增「编辑 > 整体平移…」：偏移量（±时:分:秒.毫秒 或 ±帧）、范围（当前轨道 / 选中字幕 / 全部轨道）、一次撤销；负值钳到 0 并提示；有帧索引时按帧对齐且不改变时长。
- 验收标准：
  - [ ] 两轨各 10 条整体 +500ms，链接与时长不变，一次撤销恢复。
  - [ ] 最早字幕 1s 时偏移 −2s 钳到 0，并提示。
  - [ ] 25fps 下结果落在 40ms 帧边界；无帧索引时按毫秒。
- 改动面：`index.html`（编辑菜单 + 对话框）、`workspace.mjs`（命令/范围/撤销）、`core/project.mjs`（批量平移纯函数）、`test/timing.test.mjs`、桌面 smoke。
- 工作量：S–M；风险：低。

### P0-3 查找与替换（含正则）

- 用户可见行为：⌘F 打开查找条，支持当前轨道/全部轨道、区分大小写、正则、仅正文（ASS 标签默认掩码）、替换/全部替换、命中计数与逐条定位；一次撤销或按条撤销（先定规则）。
- 验收标准：
  - [ ] 正则 `\s+$` 命中并替换全部行尾空格。
  - [ ] 替换 ASS 正文默认不破坏 `{...}` 标签。
  - [ ] 跨轨道计数正确；替换后一次撤销完整恢复。
  - [ ] 无命中、非法正则、空查找词都有明确提示。
- 改动面：新增 `src/core/text.mjs`（查找/替换 + 标签掩码纯函数）、`workspace.mjs`（UI/选中/撤销）、`index.html`、`test/text.test.mjs`、桌面 smoke。
- 工作量：M；风险：中（ASS 标签掩码）。

### P0-4 双语合并导出

- 用户可见行为：导出对话框新增「合并上下轨为双行字幕」；规则先固定为：上轨在前、时间取交集、单边缺失保留单行并计数提示；ASS 导出样式取上轨。
- 验收标准：
  - [ ] 两条链接轨各 100 条导出成对 200 行。
  - [ ] 时间差 200ms 的链接按交集规则输出，并在预览中显示示例。
  - [ ] 3 条单边保留并提示；无链接轨时给出可读错误。
- 改动面：新增 `src/core/merge.mjs`、`workspace.mjs`（导出流程）、`index.html`（导出对话框）、`main.mjs`（批量导出 IPC）、`test/`、桌面 smoke。
- 工作量：M；风险：中（产品规则需拍板）。

### P0-5 Windows 发布链路

- 用户可见行为：Windows 安装后无需自备 FFmpeg 即可合成视频；安装/卸载/文件关联/合成全流程可用。
- 验收标准：
  - [ ] 干净 Windows 环境安装后，空白视频合成 H.264 成功。
  - [ ] 安装包包含 `ffmpeg.exe/ffprobe.exe`；`.subx` 双击可打开。
  - [ ] 卸载无残留；`scripts/desktop-smoke/windows-installer.ps1` 在 CI 常规执行。
- 改动面：`scripts/fetch-ffmpeg.mjs`（win32-x64 源 + SHA256）、`forge.config.cjs`（extraResource）、`.github/workflows/desktop.yml`、`windows-installer.ps1`、`README.md`。
- 工作量：M–L；风险：高（外部二进制、签名、干净机）。

## 5. P1 公测必备清单

### P1-1 质量检查（QC）

- 行为：QC 面板列出 CPS 超阈值、时长过短/过长、空行、行尾空格、同轨重叠、标点问题；点击定位；批量修复（延长/拆分/去空格）；阈值可配（CPS 默认 17，时长 1–7s）。
- 验收：30 条含 5 类问题的样例计数/定位准确；批量修复一次撤销；阈值随工程保存。
- 改动面：新增 `src/core/qc.mjs`、`workspace.mjs` + `index.html`（QC 面板）、`project.mjs`（settings 校验）、`test/qc.test.mjs`。
- 工作量：M。

### P1-2 文本工具

- 行为：整轨/选中范围拼写检查（系统字典 + 自定义词典、忽略/加入词典）；大写/小写/首字母/句首；批量修剪空格。
- 验收：英文 20 条样例检出全部错误且中文默认不误报；大小写只改正文、不破坏 ASS 标签。
- 改动面：`main.mjs`（spellchecker）、`preload.cjs`、`workspace.mjs` + `index.html`、`core/text.mjs`。
- 工作量：M。

### P1-3 帧率转换与时间码

- 行为：支持 23.976/24/25/29.97/30/50/59.94/60 的比例缩放（全部/选中轨道，保持链接）；时间码按真实帧索引显示，支持毫秒/非丢帧/丢帧格式。
- 验收：24→25 全片时间按比例缩放误差 ≤1ms/条；29.97 素材 10 分钟后时间码与实际帧号偏差 ≤1 帧；一次撤销恢复。
- 改动面：新增 `core/retime.mjs`、`core/timecode.mjs`、`workspace.mjs`（标尺/时间码/表单）、`index.html`（项目设置）、`test/`。
- 工作量：M–L。

### P1-4 格式与编码

- 行为：WebVTT 导入/导出（`<i>/<b>` 简单映射）；SSA `[V4 Styles]` 兼容；GBK/GB18030 导入；导出可选 UTF-8 / UTF-8 BOM / UTF-16LE / GB18030 与 LF/CRLF。
- 验收：SRT↔VTT 往返文本/时间一致；GBK SRT 中文正确解码；导出 GBK 在 Windows 记事本正常；BOM/换行字节正确。
- 改动面：新增 `core/vtt.mjs`、`main.mjs`（解码/编码/过滤）、`index.html`（导出选项）、`workspace.mjs`、`test/`。
- 工作量：M。

### P1-5 工程健壮性

- 行为：撤销步数可配并按内存上限裁剪；大工程快照优化；工程格式版本迁移；损坏工程给中文错误而非 JS TypeError。
- 验收：5000 条工程连续 200 次编辑不 OOM；旧版本工程可打开并提示迁移；缺 `tracks/styles` 返回可读错误。
- 改动面：`workspace.mjs:408-430`、`project.mjs:57-101`、`main.mjs:365-391`、`test/`。
- 工作量：M。

### P1-6 批量编辑

- 行为：多选后批量设置起/止/时长/平移；批量改样式字段（并提示共享样式影响范围）；批量文本操作。
- 验收：选中 50 条 +200ms 一次完成、一次撤销；批量改字号影响引用该样式的字幕并明确提示。
- 改动面：`workspace.mjs`（多选编辑面板）、`index.html`、`project.mjs`（批量 helper）、`test/`。
- 工作量：M。

### P1-7 校对工作流

- 行为：任意字幕可标「已校对/待校对」，进度显示 n/m，按状态筛选与跳转；拆分异常沿用现有标记。
- 验收：标记 10/100 后进度 10%；筛选仅显示待校对；保存重开保留。
- 改动面：`project.mjs`（cue 标记 + 校验）、`workspace.mjs:936-943,3318-3351`、`index.html`、`test/`。
- 工作量：S–M。

### P1-8 性能压测

## 10. 风险与开放决策

### 10.1 风险

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 自动保存与退出/保存竞态 | 数据损坏 | 复用 `writeAtomically`；单飞写队列；恢复文件只读校验 |
| 撤销全量快照内存 | 大工程 OOM | 内存上限 + 结构共享/命令式撤销（M1 评估） |
| 双语合并规则反复 | 返工 | 先按 §4 P0-4 默认规则实现，公测前只允许一次调整 |
| Windows FFmpeg 来源/签名 | 无法发布 | 固定版本 + SHA256 + 离线缓存；提前在干净机验证 |
| 5000 块性能不达标 | 大工程不可用 | M3 前完成压测，必要时虚拟化/增量渲染 |
| 字体不一致 | 成片与预览不同 | 合成前字体检查 + 内置 Noto 回退 |

### 10.2 开放决策（需要用户拍板）

1. 双语合并规则：上轨在前还是下轨在前；时间不一致取交集/并集/上轨优先；单边缺失是否保留。
2. Windows 签名与公证预算：是否购买代码签名证书；beta 是否接受 SmartScreen 提示。
3. QC 默认阈值：CPS 17 是否合适；最短 1s / 最长 7s 是否按语言区分。
4. 撤销策略：70 步是否保留；是否改为内存上限。
5. VTT 是否进公测 P1，还是放到 P2。
6. 拼写检查是否进公测（系统字典 + 自定义词典）。
7. 自动更新是否进公测（建议先手动下载）。
