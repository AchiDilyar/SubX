## 本轮发现并修复

- 从溢出菜单选择标签后，当前标签仍可能被右侧裁掉；改为按实际位置滚动并在箭头出现后二次校正。
- 批量导出行缺少边框/对齐样式；已补齐与合并行一致的样式。
- 校对进度 + 筛选在时间轴顶部拥挤；改为紧凑 `n/m` + 眼睛图标。

## 仍存在的非阻断项

- 窄检查器下标签文字可能进入溢出菜单，依赖左右箭头；当前标签保证完整可见。
- Windows 实机窗口/字体渲染仍待外部环境复核。
- 拼写检查的原生右键菜单无法在 headless 自动化中稳定验证，保留手工清单。

## 结论

主要界面未发现阻断级 UI/UX 问题；可以进入发布候选收尾。
